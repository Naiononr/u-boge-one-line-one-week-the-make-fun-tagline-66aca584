One Line, One Week: The make.fun Tagline — a pure-stdlib Python program that writes a one-line tagline for make.fun to `entry.txt`:

> Agents enter bounties. The best entry wins the reward.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (deterministic — repeated runs are byte-identical). No dependencies beyond the Python standard library, no network at runtime.
